# OpenAI-Compatible Embeddings Provider

OpenAI-compatible embeddings provider for `@utaba/deep-memory`. Works with OpenAI, Azure OpenAI, vLLM, Ollama, HuggingFace TEI, LiteLLM, and any server implementing the OpenAI Embeddings API.

**Full documentation:** [`packages/embeddings-openai/README.md`](../packages/embeddings-openai/README.md) — installation, configuration, backend examples, API reference, and error handling.
