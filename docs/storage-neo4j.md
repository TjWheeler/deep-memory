# Neo4j Storage Provider

Neo4j implementation of both `StorageProvider` and `GraphTraversalProvider` for `@utaba/deep-memory` — persistent graph storage plus native Cypher graph queries from a single provider, backed by Neo4j Community Edition (5.24 or later) over Bolt.

**Full documentation:** [`packages/storage-neo4j/README.md`](../packages/storage-neo4j/README.md) — installation, configuration (including `vocabularyCacheTtlMs` and `searchScoring`), lifecycle, label scheme + schema DDL, slug uniqueness, the vocabulary cache, vocabulary writes and the change log, repository delete and `RepositoryNotFoundError` on every repository-scoped call, batched type deletes, upgrading (schema version 2 and how to roll back), search behaviour (fulltext vs CONTAINS, search ordering and the multi-tenant caveat), graph traversal capabilities, bulk operations (relationship-id rules and the import error policy), retry safety and the error mapping, usage tracking, local development setup, AuraDB deployment, differences from the CosmosDB provider, and licensing.
