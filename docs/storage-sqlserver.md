# SQL Server Storage Provider

SQL Server implementation of the `StorageProvider` interface for `@utaba/deep-memory`. Provides persistent, multi-tenant graph storage backed by SQL Server (2016+).

**Full documentation:** [`packages/storage-sqlserver/README.md`](../packages/storage-sqlserver/README.md) — installation, connection options, lifecycle, schema management (automatic + manual + static DDL), table layout, multi-tenancy, query capabilities, bulk operations, and testing.
