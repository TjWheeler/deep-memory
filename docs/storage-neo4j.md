# Neo4j Storage Provider

Neo4j implementation of both `StorageProvider` and `GraphTraversalProvider` for `@utaba/deep-memory` — persistent graph storage plus native Cypher graph queries from a single provider, backed by Neo4j Community Edition over Bolt.

**Full documentation:** [`packages/storage-neo4j/README.md`](../packages/storage-neo4j/README.md) — installation, configuration, lifecycle, label scheme + schema DDL, search behaviour (fulltext vs CONTAINS), graph traversal capabilities, bulk operations, usage tracking, local development setup, AuraDB deployment, differences from the CosmosDB provider, and licensing.
